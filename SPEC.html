01제품 정의

Linear Algebra Sandbox는 선형 변환을 직접 조작·관찰하며 직관을 쌓도록 설계된 학습용 웹 도구입니다. 벡터를 추가하고, 회전·전단·스케일 등의 행렬을 적용하면 격자와 벡터가 함께 변하는 모습을 시각적으로 확인할 수 있습니다.

  • 두 가지 독립 모드: 2D(기본) / 3D(우상단 토글로 전환, lazy 로드)
  • 모든 UI는 한국어, 어려운 개념은 각 섹션 안에 “사용법 & 예시” 도움말로 내장
  • 변환 이력 타임라인 스크럽, 단계별 재생, 자동 재생, 속도 조절(🐇~🐢)
  • 고유값·고유벡터, 영공간, 행렬식 면적/부피, 기저 변환, 내적/외적 등 핵심 개념 시각화

05수학 코어 (mat2 / mat3)

2D — mat2

row-major flat array [a, b, c, d] = [[a,b],[c,d]]

API설명
identity()[1,0,0,1]
mul(a, b)행렬 곱 A·B (4×4 곱셈 식 직접 전개)
apply(m, v)2D 벡터에 행렬 적용
det(m)행렬식 ad − bc
inv(m)역행렬, |det| < 1e-10이면 null 반환
lerp(a, b, t)요소별 선형 보간 (애니메이션용)
eigen(m)특성방정식 직접 풀이, 실수 고유값만 반환. 복소 고유값 시 []. 결과는 단위벡터로 정규화됨

3D — mat3 (src/mat3.js)

row-major flat array [a,b,c, d,e,f, g,h,i]

API설명
identity / mul / apply3×3 기본 연산
det(m)여인수 전개로 계산
inv(m)여인수 행렬 / det, |det| < 1e-10이면 null
transpose / lerp전치 / 요소별 보간
rotX / rotY / rotZ축 기준 회전 행렬 (라디안 입력)
eigen(m)3차 특성다항식을 Cardano/삼각법으로 풀어 실수 고유값 추출 → (M − λI)v = 0 null space는 행 cross product로 구함
cross3 / vec3Len외적, 길이 보조 함수 (export)

06렌더링 모델

항상 동작하는 rAF 루프

useEffect 안에서 무조건 매 프레임 requestAnimationFrame을 돌리는 단일 루프 구조입니다. 애니메이션 활성 여부와 무관하게 카메라 이동, 드래그, 하이라이트 변경이 즉시 반영됩니다.

애니메이션 중에는 animRef.current.{from, targetMatrix, start, duration}을 읽어 eased t로 mat.lerp(from, target, t)를 currentMatrixRef.current에 직접 기록합니다. 완료 시 setCurrentMatrix로 React state에 커밋합니다.

Easing은 ease-in-out quadratic 한 가지: t < 0.5 ? 2t² : 1 − (−2t+2)²/2

적응형 격자 (2D)

줌(픽셀 / 월드 1단위)에 따라 8단계로 자동 전환:

zoom (px/unit)gridStep
> 1500.5
> 351
> 152
> 75
> 310

> 0.550
그 외100

변환된 격자는 Math.min(200, tgRange)로 그리는 선 수가 제한되어 극단 줌·변환에서도 성능 보호됩니다.

2D 좌표 변환

worldToScreen(wx, wy)
  = [ W/2 + (wx − cam.x) · zoom ,  H/2 − (wy − cam.y) · zoom ]

screenToWorld(sx, sy)
  = [ (sx − W/2) / zoom + cam.x ,  −(sy − H/2) / zoom + cam.y ]

Y축은 월드 위→스크린 아래로 부호 반전. 카메라 zoom 범위: [10, 300].

3D 투영

Y축 회전 → X축 회전 순서의 직교 투영(orthographic). 카메라는 { rotX, rotY, zoom, panX, panY }로 구성된 오빗 카메라이며, Shift+드래그로 패닝, 일반 드래그로 회전, 휠로 줌([10, 300]) 합니다. 단위 정육면체의 6면을 painter’s algorithm(평균 z 기준 정렬)으로 그려 부피 변화를 보여줍니다.

07상태 관리 모델

Dual ref 패턴

rAF 루프 내부의 stale closure를 피하기 위해, 렌더가 매 프레임 읽어야 하는 모든 state는 useRef로 미러링됩니다. 갱신 시 setter와 .current를 같이 써야 합니다. 

const [transformHistory, setTransformHistory] = useState([]);
const transformHistoryRef = useRef(transformHistory);
transformHistoryRef.current = transformHistory;  // 매 렌더마다 동기화

대상 state: camera, vectors, transformHistory, transformMeta, currentMatrix, animSpeed 등.

변환 이력 + 메타데이터 (병렬 배열)

state역할
transformHistory적용된 행렬 [a,b,c,d] 또는 […9]의 시계열 배열
transformMeta각 항목의 라벨 — 프리셋 한국어 이름 / 사용자정의 [a,b;c,d] / A[…] × B[…] / 회전 30° ↺
timelinePos0 ~ history.length 사이 스크럽 위치
currentMatrix실제 화면에 반영된 누적 행렬 (애니메이션 도중에는 중간값)

getEffectiveMatrix(pos)는 identity에서 시작해 pos까지의 행렬을 좌측 곱셈(mul(hist[i], m))으로 누적합니다. 스크러버 위치 조작·뒤로 가기 시 모두 이 함수가 진실의 원천입니다.

애니메이션 / 자동 재생

  • 속도: 2D 기본 800ms/step, 3D 기본 500ms/step. 슬라이더 범위 200~3000ms.
  • 단계 이동: stepForward / stepBackward — 현재 행렬에서 다음/이전 누적 행렬로 lerp.
  • 자동 재생: autoPlayAll — identity로 리셋한 뒤 한 단계가 끝날 때마다 200ms 지연 후 다음 단계 체이닝.
  • 되감기: rewindLast — 마지막 변환의 det가 0이면 토스트 경고하고 중단.

08인터랙션 사양

2D 모드

  • 캔버스 드래그: 카메라 패닝
  • 화살표 끝 드래그: 해당 벡터 이동 (0.5 단위 스냅)
  • 벡터 hover: 좌표 툴팁 표시
  • 외적 모드 활성 시 클릭: 벡터 2개 선택 → 자동으로 3D 미니뷰 오픈
  • 휠 스크롤: 줌 (×0.9 / ×1.1, clamp [10, 300])

3D 모드

  • 드래그: 오빗 회전 (rotX/rotY 동시 조정, ×0.4 감도)
  • Shift + 드래그: 카메라 패닝
  • 휠 스크롤: 줌 (×1.1 / ×0.9, clamp [10, 300])
  • 벡터는 (x, y, z) 입력으로만 추가/삭제, 캔버스 드래그 미지원
벡터 드래그 시 좌표 역산 — 현재 행렬의 역행렬을 마우스 월드 좌표에 적용해 “변환 전 좌표”를 구한 뒤 저장합니다. mat2.inv가 null이면(특이 행렬) 화면-월드 좌표를 그대로 사용하는 폴백이 동작합니다.

⑤변환 이력적용된 변환 리스트, 라벨/행렬값/det 표시, timelinePos 이하 항목은 강조 색상
⑥격자 & 행렬식원본 기준 격자 토글, 단위 면적(det) 음영 토글
⑦역변환 & 영공간⏪ 되감기(det=0 검사), ⟲ 전체 초기화. det≈0이면 빨간 점선으로 영공간 자동 표시
⑧내적 & 쌍대성벡터 1개를 기준으로 선택 → 나머지 벡터들을 그 방향 직선에 수직 투영, dot=값 라벨
⑨외적 (3D)“두 벡터 선택” 모드 진입 → 캔버스에서 2개 클릭 → 회전 가능한 SVG 3D 평행사변형 + z축 외적 벡터 오버레이
⑩고유벡터금색 라인 + λ 라벨. 항등 행렬이면 “모든 벡터가 고유벡터”라고 안내, 복소 고유값이면 “실수 고유값 없음”
⑪기저 변환b₁, b₂ 입력 → 보라/분홍 격자 + 각 벡터 옆에 alt 좌표 자동 표기

상단/하단 고정 UI

  • 상단 중앙: 현재 누적 행렬([a,b;c,d]) + det 실시간 표시 (det<0이면 빨강)
  • 하단 타임라인: ⟲ ⏪ ◀ ▶ ▶▶/⏹, 스크러버 + 단계 점, Step n/N 표시, 🐇🐢 속도 슬라이더
  • 하단 좌측 오버레이: “변환 과정” 체인(라벨 → 라벨 = 최종 행렬), Mat×Vec / Mat×Mat 식 표시 (실시간)
  • 경고: |det| < 0.05이면 하단 중앙에 펄스 경고, det < 0이면 우하단에 “공간 방향 반전” 배지
  • 토스트: 중앙 모달, 3.5초 자동 사라짐 + 닫기 버튼 (예: 되감기 불가 알림)

13엣지 케이스 & 경고 UX

되감기 차단 (det = 0)
rewindLast는 마지막 변환의 |det| < 1e-10이면 “차원이 축소되어 정보 손실” 토스트를 띄우고 동작하지 않습니다. 수학적으로 역행렬이 없기 때문.
항등 행렬에서 고유벡터

실시간 시각 경고
  • |det(currentMatrix)| < 0.05 & 변환 이력이 있음 → 하단 중앙에 펄스 경고 “det ≈ 0 차원 축소”
  • det(currentMatrix) < -0.01 → 우하단에 “공간 방향 반전 (det < 0)” 표시
  • 그리드/단위면적 음영 색상도 det 부호에 따라 빨강/주황으로 자동 전환
